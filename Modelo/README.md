# Modelo Base de Exercícios

Esta pasta (`Modelo`) serve como um **molde padrão** para agilizar o início dos próximos exercícios e projetos práticos ao longo do curso.

## Finalidade
* **Padronização:** Mantém a estrutura base de arquivos e pastas organizada desde o início.
* **Agilidade:** Evita a necessidade de criar e configurar os arquivos iniciais do zero a cada nova atividade.

## Como usar
1. **Copie** esta pasta `Modelo` sempre que for iniciar um novo exercício.
2. **Renomeie** a cópia de acordo com o tema ou número da atividade (ex: `Exercicio01`, `CalculadoraIMC`).
3. **Desenvolva** o código na pasta copiada, mantendo o `Modelo` original intacto para uso futuro.
