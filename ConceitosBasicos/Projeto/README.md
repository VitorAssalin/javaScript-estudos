# Exercício: Cadastro de Pessoas

Projeto prático desenvolvido para marcar a **conclusão da seção de Conceitos Básicos de JavaScript** do curso.

## O que faz
Captura os dados preenchidos em um formulário HTML (nome, sobrenome, peso, altura e idade), armazena em um array de objetos e exibe o resultado na tela sem recarregar a página.

## O que foi utilizado
- **HTML5:** Estrutura do formulário e inputs.
- **JavaScript:** Manipulação do DOM (`querySelector`, `innerHTML`), eventos (`addEventListener`, `preventDefault`), funções, arrays e objetos.
